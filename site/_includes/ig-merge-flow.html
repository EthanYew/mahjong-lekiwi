  7. ResultMain codebase

    What runs on the robot.

  8. ResultStatus report

Guardrails around every step

Rule files

One per area, in plain English, loaded automatically. Each records a lesson the hardware taught (9 files).

Simulated robot + motion watchdog

Every test runs on a fake arm; any command that breaks a motion rule fails the test (1,300 tests, 11 s fast set).

Arm gate

Any command that would move the real arm asks a person first, even when the agent works on its own.
